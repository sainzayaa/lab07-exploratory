# BUG-02: API-д буруу JSON биетэй POST /api/books хүсэлт 400 биш 200 OK буцаана

Орчин: Уншлагын жагсаалт v2.0, curl 8.7.1, macOS 26.5.2, 2026-11-24

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. Терминалд node app.js-ийг шинээр ажиллуул.
2. Өөр терминалд дараах командыг ажиллуул:

curl -i -X POST localhost:3000/api/books -d 'буруу оролт'

3. Гаралтын эхний мөр (статус код) болон биеийг хар.

Хүлээгдэж байсан: спецификацийн «Буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана» дүрмээр HTTP/1.1 400 (Bad Request) ба алдааны мессеж.

Бодит үр дүн: HTTP/1.1 200 OK статус ба {"result":"OK"} бие буцна, өөрөөр хэлбэл апп буруу оролтыг амжилттай гэж хүлээн авна.

Ноцтой байдал: Major. API нь буруу оролтыг алдаа гэж мэдэгдэхгүй, амжилттай гэж хариулдаг тул дуудагч систем алдааг илрүүлж чадахгүй.
